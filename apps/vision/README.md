# Reframe vision

This Python 3.12 application hosts private, provider-backed spatial inference.
Its capability profiles isolate semantics, metric depth, mapping, geometry, and
reveal work behind typed, authenticated boundaries.

## Ownership

Vision workers may return digest-bound masks, depth, geometry, and reveal
artifacts with readiness and provenance. They never own public object identity,
ARKit pose authority during a healthy native session, scene revisions,
eligibility, confirmation, commit, reconciliation, or restore.

Workers admit bounded work, expose independent capability readiness, and must
not download models during startup. Sources, environments, checkpoints,
captures, and outputs live outside Git and require pinned hashes and licenses.

## Commands

```sh
uv sync --frozen
uv run --frozen ruff format --check .
uv run --frozen ruff check .
uv run --frozen basedpyright
uv run --frozen pytest -q
```

Run the default fail-closed worker with `uv run --frozen python -m
reframe_vision.main` after setting a private worker token. Keep its port on the
private host network.

## Known limitations

DA3 and official SAM 3.1 have separate A100 smoke evidence, but the complete
reproducible worker deployment is open. Real iPhone target tracking, robust
ARKit/depth alignment, bounded Open3D TSDF, plane atlases, the hash-verified
LaMa service, and removal-quality acceptance remain incomplete.
