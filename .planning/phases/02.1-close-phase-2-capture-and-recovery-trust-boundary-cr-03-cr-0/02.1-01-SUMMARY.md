# Phase 02.1 Plan 01: Verified Archive Capability Summary

**Replay authority is now an opaque, immutable, generation-bound capability minted only after complete pinned contract and semantic verification, with exact member identity re-established immediately before replay.**

## Accomplishments

- Added the sole `ArchiveVerifier`, which validates canonical CON-002 bytes and every referenced CON-001 packet with its exact payload before enforcing bounded inventory, identity, session/world, sequence, lifecycle, idempotency, path, projection, and digest bindings.
- Added an opaque `VerifiedArchive` whose initializer and storage remain file-private while its public immutable descriptors bind one source and content-addressed generation to every accepted member.
- Removed raw-URL replay admission. `ReplayCore` accepts only a verifier-issued capability, reconstructs the journal-authoritative timeline from typed verified content, and maps failures to stable non-sensitive errors.
- Added admission and TOCTOU coverage for the complete D-13 mutation matrix, unforgeable public API probes, sequential/concurrent determinism, and unrelated-file noise.

## Decisions Made

- A URL, root reader, or cached boolean cannot encode replay authority. Only the non-forgeable capability crosses the verifier-to-replay boundary.
- The capability freezes public value descriptors but not a trusted assumption about mutable filesystem state. Each dependent member is bounded-read and rehashed before any timeline entry is returned.
- Open archives are not replay candidates. A structurally and semantically valid open root can enter later recovery logic only through a separate internal capability.
- Caller propagation uses the existing exact pinned contract registry inputs. No schema, dependency, compatibility policy, or package manifest changed.

## Threat Model Closure

- **T-02.1-01 (archive tampering): mitigated.** Pinned schema validation, full semantic bindings, safe normalized paths, bounded reads, and rehashed mutations all run before minting.
- **T-02.1-02 (capability privilege escalation): mitigated.** `VerifiedArchive` has no public or package initializer, and ReplayCore has no raw-root overload.
- **T-02.1-03 (post-admission tampering): mitigated.** Replacement, symlink, truncation, and manifest substitution fail before a replay snapshot exists.
- **T-02.1-04 (error disclosure): accepted as planned.** Stable rejection classes do not log room bytes or host paths.
