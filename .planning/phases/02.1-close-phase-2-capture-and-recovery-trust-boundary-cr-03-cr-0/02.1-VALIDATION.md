## Required Adversarial and Fault Matrix

### `CR-03` — trust admission

- False consent/privacy state and unknown manifest/packet members.
- Invalid stable IDs, event types, lifecycle transitions, and idempotency
  bindings.
- Session, world epoch/version, frame, event, journal, sequence, projection,
  path, payload, and digest mismatches.
- Invalid RR-FLOAT/transform values, traversal/symlink paths, and oversized
  bounded input.
- Exact-member substitution after successful verification.
- Each archive is rehashed after mutation and enters through the production
  verifier; no case may produce `VerifiedArchive` or a replay record.

### `CR-04` — durable prefix

- Every existing record-first writer observation boundary.
- A valid, fsynced journal record beyond a stale open-manifest projection.
- Terminal partial/corrupt tails recover only the prior verified prefix.
- Gap, duplicate, reorder, later-valid-after-fault, or referenced-byte
  contradiction fails closed as interior corruption.
- Recovered projections, inventory, sequences, and replay digest are rebuilt
  from exact referenced bytes rather than copied from the stale manifest.

### `CR-12` — atomic publication

- Process-death injection before and after each generation-member write and
  file synchronization, directory synchronization, generation rename, and
  active-pointer replacement.
- Restart validation at every boundary: the prior pointer or one fully verified
  generation is visible; no half archive/quarantine result is visible.
- Repeated two-publisher races for identical and different valid generation
  candidates.
- Cleanup assertions proving an invocation removes only its uniquely owned
  staging paths and never a winner, pre-existing generation, or active pointer.
