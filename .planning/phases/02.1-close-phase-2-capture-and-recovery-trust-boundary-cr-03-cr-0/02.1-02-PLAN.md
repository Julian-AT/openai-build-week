| Boundary | Description |
|---|---|
| Physical JSONL journal -> reconstructor | Crash-torn and attacker-modified bytes determine the only replay order and must be classified without repair. |

| Reconstructed candidate -> later publisher | The candidate is not visible authority until Plan 03 verifies and commits it. |
