# ReRoom 36-Hour Demo Sprint Cut

**Approved by:** Human project owner
**Approved at:** 2026-07-18
**Timebox:** 36 hours
**Delivery classification:** Demo candidate; not a fully gated P0 release

## Purpose

Ship the smallest honest ReRoom demonstration that preserves the four native
operations (`place`, `replace`, `remove`, `restore`) and a separate
provider-independent Mode B0 replay/inspection path. The sprint prioritizes a
working vertical journey over repeating already-covered evidence campaigns.

This overlay changes sequencing and sprint acceptance only. It does not delete,
weaken, or mark any canonical requirement, ADR, contract, test, or gate green.
Deferred proof remains `PENDING` until its real evidence exists.

## Sprint-Critical Delivery

1. Close the Phase 2 implementation with automated capture/replay evidence and
   one signed-device pressure/recovery smoke run.
2. Build one deterministic native hero vertical supporting exactly place,
   replace, remove, and compensating restore.
3. Use explicit tap/manual target selection and bounded supported-view behavior.
4. Build the smallest separate Next.js B0 experience that can verify, replay,
   scrub, and inspect a capture with learned providers disabled.
5. Retain typed/tap safety, stable IDs, exact revisions, replay authority,
   consent, and fail-closed boundaries.
6. Reserve the final sprint window for integration, demo capture, submission,
   and an honest pending-gate report.
